Écritures à connaître par cœur

\[\text{rect}_T(t) = u(t+\tfrac T2)-u(t-\tfrac T2) \qquad r(t) = t\,u(t)\] \[\text{tri}_T(t) = \tfrac1T\big[r(t+T)-2r(t)+r(t-T)\big]\] \[\int_{-\infty}^{\infty}\phi(t)\,\delta(t-t_0)\,dt = \phi(t_0) \qquad \delta(at)=\tfrac{1}{|a|}\delta(t)\] \[e^{j\omega_0 t} = \cos\omega_0 t + j\sin\omega_0 t\]

Pièges fréquents

  • Un signal impair vaut forcément 0 en \(t=0\).
  • Somme de deux sinusoïdes : périodique seulement si le rapport des périodes est rationnel.
  • Énergie finie implique \(P=0\) ; puissance finie implique \(E=\infty\). Un signal peut n’être ni l’un ni l’autre (\(t\,u(t)\)).
  • Avec \(\delta\) : vérifier que \(t_0\) est dans les bornes d’intégration, et sortir le facteur \(1/|a|\) de \(\delta(at)\).
  • \(x(at+b)\) : le décalage réel vaut \(-b/a\), pas \(-b\).
  • \(x(t-t_0)\) avec \(t_0>0\) va vers la droite. La diapositive de l’exemple combiné dit l’inverse.
  • Un système affine (\(y = ax+b\), \(b\neq0\)) n’est pas linéaire.
  • Pour l’instabilité, un seul contre-exemple borné suffit ; pour la stabilité, il faut une borne valable pour toute entrée.
